# Forge — AI Study Planner

Forge is a premium dark-mode Next.js app for adaptive study planning with mock AI flows.

## Tech stack
- Next.js 14 + TypeScript
- Tailwind CSS
- shadcn-style reusable UI primitives
- FullCalendar
- Framer Motion
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Key routes
- `/` Landing page
- `/auth` Authentication card flow
- `/app/onboarding` 3-step onboarding wizard
- `/app/dashboard` Calendar + AI plan generation + insights
- `/app/focus` Focus mode timer experience
- `/app/subjects` Subject cards and management UI
- `/app/settings` Profile/preferences settings

## Validation
```bash
npm run lint
npm run build
```
